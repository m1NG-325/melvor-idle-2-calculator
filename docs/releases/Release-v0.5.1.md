## 简体中文

- **可以手动选存档了**：找不到角色时，直接选 `.sav` 文件。工具会记住选择，之后每 15 秒读取原文件
- **连锁产线可以按数量算**：输入想做多少，工具会算出所需材料和耗时。也可以给随机产出预留备料余量
- **技能经验可以忽略库存**：勾选后按每小时经验比较，仍会计入解锁条件、配装和成功率。低于 1 的经验收益会保留两位小数
- **修复定时挂机的汉化问题**：启动队列时沿用游戏的语言资源，遇到需要独立入口的加载器时会提示
- **优化计算和排版**：调整了地下城补给消耗和部分技能经验的计算，经验收益页面也重新排了版。右上角新增 GitHub 入口

## English

- **Choose your save manually** — If your character doesn’t show up, pick your `.sav` file. The app remembers it and rereads the original file every 15 seconds
- **Plan production by target quantity** — Enter how many items you want to make to see the materials and time required. You can add a material buffer for random yields
- **Compare skill XP rates without stock limits** — Unlocks, loadouts, and success rates still count. XP gains below 1 display with two decimal places
- **Fixed translations when starting a timed queue** — Queues use the installed game’s language files and show a message if a loader needs its own entry point
- **Calculation and layout updates** — Refined dungeon supply and some skill XP estimates, cleaned up the XP page, and added a GitHub link in the top right
