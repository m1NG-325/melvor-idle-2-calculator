## 简体中文

- **适配游戏更新**：桌面版支持新版角色存档，恢复 Steam 构建 26886380 的定时挂机
- **新增一键汉化**：内置自制简体中文，补齐物品、任务和界面译文，支持直接更新旧版自制汉化
- **定时挂机自动选档**：选好角色和队列，工具就会启动游戏并载入角色。手动选档会核对文件，找不到存档或载入超时会停止队列
- **新增账号 Beta（未完善）**：支持用用户名和密码注册登录，可选择同步角色数据，并在手机网页控制电脑上的挂机队列
- **改进物品检索和经验收益**：支持搜索增益与减益，物品详情显示具体属性，行动名称带上一级地点

## English

- **Game update compatibility** — Read the new character save format and run timed queues on Steam build 26886380
- **One-click Simplified Chinese patch** — Install or update our translation for items, quests, and game UI
- **Auto-load for timed queues** — Start the game and load the selected character automatically. Manually selected save files are checked, and the queue stops if the save is missing or loading times out
- **Account Beta** — Sign in with a username and password, opt in to character sync, and control your desktop queue from a phone browser
- **Item lookup and XP improvements** — Search for buffs and debuffs, see item stats, and find the parent location for actions
